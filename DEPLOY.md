# Публикация сайта LUSTRE

Проект является обычным статическим сайтом. Команды сборки и серверная среда не требуются.

## GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки, включая `index.html` и папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

Для собственного домена укажите его в настройках Pages. GitHub покажет необходимые DNS-записи. После этого можно создать в корне файл `CNAME`, содержащий только имя домена, например `wash.example.ru`.

## Cloudflare Pages

1. Создайте проект Pages и подключите репозиторий с этими файлами либо загрузите папку напрямую.
2. Framework preset: **None**.
3. Build command: оставить пустым.
4. Build output directory: `/`.
5. После первого развёртывания добавьте собственный домен в разделе **Custom domains**.

## Перед реальным запуском

- замените демонстрационные телефон, адрес, цены и ссылки;
- добавьте реальные фотографии и отзывы с разрешения клиентов;
- подключите карту;
- замените демонстрационную функцию `submitBooking()` в `script.js` на запрос к вашему API, CRM или Telegram-боту;
- добавьте политику конфиденциальности и согласие на обработку данных;
- при необходимости подключите аналитику.

Сайт не обращается к сервисам ChatGPT и не требует от посетителей регистрации.
