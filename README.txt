LUSTRE — независимый сайт автомойки для GitHub Pages

Локальный запуск:
1. Распакуйте архив.
2. Откройте файл index.html двойным щелчком в любом современном браузере.

Файлы проекта:
- index.html — структура и контент;
- style.css — дизайн, адаптивность и анимации;
- script.js — меню, калькулятор, сравнение «до/после» и форма;
- images/ — локальные изображения сайта.
- DEPLOY.md — публикация на GitHub Pages или Cloudflare Pages.

Перед реальным запуском замените демонстрационные контакты, адрес, цены,
отзывы и фотографии. Для отправки заявок подключите функцию submitBooking()
в script.js к своему backend API, CRM или Telegram-боту.

Сайт не требует сборки, внешних библиотек или аккаунта на какой-либо платформе.
Все HTML, CSS, JavaScript и изображения находятся внутри этой папки.
